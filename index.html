Whole piece

Click the timeline to jump to a bar. Crosshatched rows are extra players.

Piece and tempo

Seconds per bar = beats per bar × 60 ÷ tempo × repeats. Sections can override the tempo and beats per bar. Leave tempo blank to work in bars only.

Sections

Enter the first bar of each section from your score. A section runs until the next one starts.

Type or paste the first bar of each section in table order, separated by commas or spaces.

Parts

One row per player’s line. Piano 3, Piano 4 and Marimba 3 each have a second-player row for the passages where two people share the part; log it only where the second player is in. Add more rows the same way if you find other shared parts. Station is where the instrument sits on stage (e.g. “L”, “C”, “R”); switching between stations can require extra time. Parts with the same shared-button name are logged with one button but still count as separate players. Tick “Own part only” for players who never cover anything else, and “Extra player” for second and third players on a shared part (they’re crosshatched on the timeline).

Pairing rules

“Same player” pairs are always kept together, like a clarinet and its bass clarinet. “Never together” pairs are kept apart regardless of timing.

Changeover rules

A doubling needs this much silence between one instrument stopping and the next starting. Seconds use the low end of any repeat range, so they’re the worst case.

Sign in to edit

Anyone with the link can view. To make changes, you need to be a collaborator on the GitHub repository and paste a GitHub token below. The token stays in this browser only.

How to get a token
  1. Make sure the repository owner has added you as a collaborator (repository Settings → Collaborators) and you’ve accepted the invitation.
  2. On GitHub, open your profile picture → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
  3. Give it a name such as “18 Musicians”, choose an expiration date, and tick only public_repo (or repo if the repository is private).
  4. Generate the token, copy it, and paste it above.

If the repository belongs to a GitHub organization, a fine-grained token limited to this one repository with “Contents: Read and write” also works.
